# Wafy 🌿

An ultra-lightweight, fast desktop messaging client for Linux.

Keep your chats running smoothly in the background without slowing down your computer.

---

## ✨ Features

* **Lightweight & Fast:** Uses minimal memory (RAM) and starts up instantly, keeping your system responsive.
* **System Tray Integration:**
  * **Left-click:** Instantly opens or brings your chats to the front.
  * **Right-click:** Opens quick options (Open, Reload, Quit).
  * Shows unread message indicators so you never miss an update.
* **Close to Tray:** Closing the window minimizes to your panel tray so messages keep arriving quietly in the background.
* **Desktop Notifications:** Receive native desktop alerts whenever a new message arrives.
* **Voice Notes & Media:** Full support for playing audio, recording voice messages, and sending media.
* **Dark Mode & Clean Design:** Sleek modern styling that matches your desktop theme with slim, unobtrusive scrollbars.

---

## 📥 Download & Install

Wafy is packaged for Debian, Ubuntu, Linux Mint, Pop!_OS, and other Debian-based Linux systems.

### Quick Install:

1. Go to the **[Releases Page](https://github.com/RKZIO/wafy/releases)**.
2. Download the latest installer (`Wafy_*_amd64.deb`).
3. **Double-click** the downloaded `.deb` file to install it with your system's Software installer.

*(Or install via terminal in your Downloads folder)*:
```bash
sudo dpkg -i Wafy_*_amd64.deb
sudo apt-get install -f
```

4. Open **Wafy** from your application menu!
