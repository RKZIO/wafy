# Wafy 🌿

An ultra-lightweight desktop messaging client for Linux.

Keep your chats running smoothly in the background without slowing down your computer.

---

## Features

* **Low Memory Usage:** Stays light on RAM and starts instantly.
* **Background Tray & Notifications:** Minimizes to your panel tray with unread message alerts.
* **Audio & Media:** Full support for voice notes and sending media.
* **Theme Matching:** Adapts cleanly to dark and light desktop themes.

---

## Installation

Download and install on Ubuntu, Debian, Linux Mint, and derivatives:

1. Download the latest installer (`.deb`) from the **[Releases Page](https://github.com/RKZIO/wafy/releases)**.
2. Double-click the file to install with your system's software manager.

*(Or install via terminal)*:
```bash
sudo dpkg -i Wafy_*_amd64.deb
sudo apt-get install -f
```
